# Rupam Das - Portfolio Website

Welcome to my personal portfolio website, hosted on GitHub Pages at:
👉 **[https://itsrupamdas.github.io/](https://itsrupamdas.github.io/)**

## 🚀 Overview
A lightweight, modern, responsive portfolio built entirely with clean **HTML5**, **CSS3**, and **Vanilla JavaScript**.

### Features:
- 📱 **Fully Responsive Layout**: Seamless experience across mobile, tablet, and widescreen desktop displays.
- 🎨 **SVG Portfolio Slides Viewer**: Interactive gallery and fullscreen lightbox showcasing high-resolution vector design slides.
- 🕒 **Live Digital Clock**: Real-time localized time display widget.
- ⚡ **Zero Dependencies / Frameworks**: Ultra-fast load times and instant deployment on GitHub Pages.
- 📬 **Direct Contact & Social Profiles**: Integrated links for GitHub, LinkedIn, Email, and WhatsApp.

## 🌐 Deploying to GitHub Pages

1. **Create Repository**:
   - Repository Name: `itsrupamdas.github.io`
   - Visibility: `Public`
2. **Upload / Push**:
   - Push all files from this directory to the `main` branch.
3. **Automatic Deployment**:
   - GitHub Pages will automatically serve `index.html` at `https://itsrupamdas.github.io/`.
